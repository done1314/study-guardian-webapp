# 复习计划

一个移动端优先、Apple 风格的本地学习督促原型。

[直接打开 Web App](https://done1314.github.io/study-guardian-webapp/)

## 使用

直接打开 `index.html` 即可。建议使用手机浏览器或窄窗口查看。

- 用户可以设置自己的计划名称，例如“小王的复习计划”。
- 数学和英语都带有可编辑学习目录，数学默认目录来自原有 21 个一级文件夹。
- 可以添加自定义任务，并设置开始日期、任务总天数、每日专注时长与学习目录。
- 每项任务的目录都能在“计划”页查看和修改，并显示已完成天数与打卡记录。
- 自定义任务支持数学、英语、政治、专业课或任意自定义分类。
- 数学、英语和计划页使用学科图标；自定义任务可从 12 种图标中选择。
- 可以提前完成未来任务；该分类的后续任务会自动前移。
- 可以把今天设为休息日，所有未完成的每日任务自动顺延。
- 日期栏提供“回到今天”，查看未来任务后可以一键返回。
- 每项任务都可以单独设置番茄专注时长，并支持开始、暂停、继续、重置和提前结束。
- 没有开启番茄钟时，可在任务的专注面板填写今天的开始、结束时间补记时长；重复记录会被拦截，误记可在“进度”页撤销。
- 必须上传学习内容照片后才能打卡。
- “进度”页合并番茄钟和补记的专注时长，支持日、周、月切换和分类饼图。
- 计划、照片缩略图和打卡记录保存在当前浏览器的 `localStorage` 中。
- 支持安装到手机或电脑桌面，并提供离线缓存。

这是纯前端原型；换浏览器或清除站点数据后记录会消失。
